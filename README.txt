Sistem ini dirancang untuk mendata, memetakan, dan melaporkan kondisi rambu-rambu evakuasi serta infrastruktur mitigasi bencana secara digital. Aplikasi ini bertujuan untuk membantu mempercepat proses monitoring, pelaporan kerusakan, dan pengambilan keputusan darurat oleh instansi terkait.
untuk fiturnya : 
Manajemen Data Pelaporan: Memungkinkan petugas atau masyarakat melaporkan kondisi rambu bencana (lokasi, status kerusakan, dan dokumentasi foto).
Pemetaan & Lokasi: Integrasi titik koordinat untuk mempermudah pelacakan posisi rambu bencana.
Dashboard Monitoring: Menampilkan rekapitulasi data laporan kerusakan rambu untuk keperluan evaluasi mitigasi bencana.
Manajemen Pengguna & Hak Akses: Pengaturan peran (role) pengguna antara pelapor, verifikator, dan administrator.
